Como conectar suas contas - passo a passo

O app usa OAuth 2.0 - o mesmo padrão do Google e Microsoft. Nenhuma senha fica gravada no arquivo. O token de acesso fica armazenado apenas no localStorage do seu navegador e pode ser revogado a qualquer momento.

${gSVG()}
Google - souagrosolucoes.com.br
1
Criar projeto no Google Cloud Console
Acesse console.cloud.google.com > crie um projeto novo (ex: "Agenda Hub")
2
Ativar as APIs
"APIs e serviços" > "Biblioteca" > ative as duas:
Google Calendar API Gmail API
3
Criar credencial OAuth 2.0
"Credenciais" > "+ Criar" > "ID cliente OAuth" > tipo: Aplicativo da Web
Origens JS autorizadas:
http://localhost file:// https://seu-usuario.github.io (se hospedar online)
4
Adicionar conta de teste
"Tela de consentimento OAuth" > "Usuários de teste" > adicione:
cleiton.trajano@souagrosolucoes.com.br
5
Colar o Client ID no arquivo
No topo do HTML, substitua:
GOOGLE_CLIENT_ID: '961137556992-utnc2a3qh89m7fh12fnesifhu76ir8r7.apps.googleusercontent.com'
${mSVG()}
Microsoft - Secullum + Rota Oeste
1
Registrar aplicativo no Azure
Acesse portal.azure.com > "Microsoft Entra ID" > "Registros de aplicativos" > "+ Novo registro"
2
Tipo de conta e URI
Tipo: Contas em qualquer diretório + pessoais
URI de redirecionamento: Web
http://localhost https://seu-usuario.github.io
3
Permissões de API (Microsoft Graph)
"Permissões de API" > "Adicionar" > "Microsoft Graph" > Delegadas:
Calendars.Read Calendars.ReadWrite Mail.Read offline_access User.Read
4
Colar o Application ID no arquivo
Em "Visão geral", copie o "ID do aplicativo (cliente)" e cole:
MICROSOFT_CLIENT_ID: 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx'
5
Ambas as contas Microsoft usam o mesmo Client ID
Ao conectar cada conta, o login_hint direcionará para o e-mail correto:
cleiton.trajano@secullumcontabilidade.com.br cleiton.barroso@gruporotaoeste.com.br

Conectar conta

Escolha o provedor para autenticar.

O login usa OAuth 2.0. Nenhuma senha fica gravada neste arquivo. O token de acesso fica no localStorage do seu navegador e pode ser revogado a qualquer momento nas configurações do Google ou Microsoft.
